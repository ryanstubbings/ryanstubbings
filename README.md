# Ryan Stubbings portfolio

Static site. No build step: upload the files as they are.

- `index.html` is the home page.
- `work/<project>/index.html` are the case studies: collingwood-football-club, melbourne-united, nike-fc-cup, npl-victoria, melbourne-city, melbourne-city-website, personal-work.
- `styles.css` holds the colours, fonts and text styles.
- `site.js` holds the motion: reveals, smooth scroll, the "Different." glitch, the cursor ring and the wireframe lens.
- `images/` holds the artwork. To upgrade an image, replace the file and keep the same file name.
- `fonts/` holds the glitch typefaces, cut down to the letters of "Different." only.

Home page covers all use one spec, 1064 x 600 px (landscape). A cover of any other shape is cropped to fit.

Publish: repository Settings > Pages > Deploy from a branch > `main` / `(root)`.
